I like seeing how the parts fit together.

I'm a 2026 Computer Engineering graduate from Pamantasan ng Cabuyao. What I enjoy most is the point where an idea stops being a sketch and gets dimensions: where each component sits, what the structure needs to hold, and how it will be assembled.

In my thesis I took that role on a three-person team. I modeled the system in 3D, drew a custom Raspberry Pi 5 enclosure in AutoCAD, then helped build, wire and assemble the prototype. Programming is the other half of my toolkit, and I learn unfamiliar technology by building with it.

01Thesis ProjectCAD · Prototype · Computer Vision

Computer Vision-Based Attendance and Access Control System

Three-person thesis for New Sinai School. My role: 3D/CAD and physical prototype designer. I planned the layout and deployment, designed the gate structure, modeled it in 3D before construction, and drew a custom Raspberry Pi 5 enclosure in AutoCAD.

  • AutoCAD
  • Blender
  • Raspberry Pi 5
  • Arduino Uno
  • Java
  • HTML/CSS
Completed Thesis

The system is a working academic prototype that can be demonstrated and repositioned for school presentations. It is not an industrial-grade product.

My contribution

  • Designed the physical layout, structure and gate, and planned component placement.
  • Built 3D models to visualize the implementation before construction (AutoCAD and Blender).
  • Designed the custom Raspberry Pi 5 enclosure.
  • Helped build the wall and gate mechanism, assemble the parts, wire them and integrate the hardware (Pi 5, Arduino Uno, webcams, monitor, servo/motor, sensors).
  • Designed and implemented the initial UI in Java, HTML and CSS.

The core computer-vision programming and circuitry were mainly done by a teammate.
